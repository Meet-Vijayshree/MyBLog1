# My Blog Website

## Project Overview
**My Blog** is a simple static blog website created using **HTML** and **CSS**. It provides a clean and structured interface for displaying blog posts, images, navigation links, and a comment section.

The project demonstrates front-end web development concepts such as page layout, styling, content organization, and user interaction design.

---

## Features
- Responsive webpage structure
- Header and navigation menu
- Multiple blog posts with images
- Blog descriptions and highlights
- Comment section for user interaction
- Footer section with copyright

---

## Technologies Used
- **HTML5**
- **CSS3**
